# Contributing

## Setup

```bash
git clone https://github.com/MathiasPaulenko/behave-runner.git
cd behave-runner
make dev
pre-commit install
```

## Workflow

1. Create a feature branch
2. Make changes
3. Run `make check`
4. Submit a pull request

## Code style

- Ruff for linting and formatting
- Mypy --strict for type checking
- Tests required for new features
