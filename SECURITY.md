# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in behave-runner, please report it by
emailing <mathias@paulenko.dev>. Do not open a public GitHub issue.

## Response Time

- Initial response: within 48 hours
- Fix or mitigation: within 7 days for critical issues

## Scope

Security vulnerabilities in behave-runner itself. Not in dependencies —
report those to their respective maintainers.
